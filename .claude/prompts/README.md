# Prompts versionados

Prompt bom é ativo do time, não conhecimento de uma pessoa.

Um arquivo por prompt recorrente, com: quando usar, o texto, e o que costuma dar errado.
Prompt que só existe na cabeça de alguém é ponto único de falha — é o risco
"prompt-conhecimento" de `sistema-qa-ia.md` §10.

## Os que já existem

| Prompt | Quando |
|---|---|
| [`extrair-rn-de-ata.md`](extrair-rn-de-ata.md) | a feature não tem documento, só a ata do refinamento |
| [`revisar-pr-de-teste.md`](revisar-pr-de-teste.md) | portão 3 — revisão de spec antes do merge |
| [`defeito-a-partir-de-log.md`](defeito-a-partir-de-log.md) | a suíte ficou vermelha e falta o ticket |

Ainda faltam: redação de charter exploratório, e extração de regra a partir de
contrato de API.

**Todo prompt aqui tem a seção "o que costuma dar errado".** Um prompt sem ela é
meio prompt: quem usa não sabe o que conferir na saída.
