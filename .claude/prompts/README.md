# Prompts versionados

Prompt bom é ativo do time, não conhecimento de uma pessoa.

Um arquivo por prompt recorrente, com: quando usar, o texto, e o que costuma dar errado.
Prompt que só existe na cabeça de alguém é ponto único de falha — é o risco
"prompt-conhecimento" de `sistema-qa-ia.md` §10.

Candidatos naturais: extração de RN de ata de reunião, revisão de PR de teste com o
checklist, redação de charter exploratório, redação de defeito a partir de log de falha.
